# PCB Layout & Fabrication Files

Place your ECAD board layout and fabrication deliverables here:
- `estero_volt_v1.0.kicad_pcb` (KiCad 7.x/8.x Board File)
- `gerbers/` (Standard RS-274X Gerber & Excellon Drill ZIP package)
- `assembly/` (Centroid / Pick-and-Place position files)

Refer to [`docs/PCB_DESIGN.md`](../../docs/PCB_DESIGN.md) for stackup definition, CPWG RF routing rules, star-grounding architecture, and conformal coating specifications.
